# xmens_final (archived)

Snakemake pipeline for the X-Mens and human endometrium Slide-tags analyses (Çevrim et al.).

Deprecated and kept for reference only. The current code is at
[McKinleyLab/xmens](https://github.com/McKinleyLab/xmens).

Layout: `workflow/` (Snakefile, rules, scripts, environments), `config/` (paths and parameters), `resources/`
(annotation tables, markers, references), `notebooks/`, `paper_code/` (code not yet ported into rules), `docs/`.
